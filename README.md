# proyectoFinalML

Repositorio oficial de la entrega del Proyecto Final para la Asignatura "Matemáticas del Aprendizaje de Máquina".

El archivo proyectoFinal.pdf contiene el paper oficial de descripción del proyecto, con sus resultados y conclusiones.

Se incluyen 4 notebooks, los primeros dos como proyectos experimentales. El notebook "03" contiene el pipeline de preprocesado de datos usado en el reporte final del proyecto. Por otra parte, el notebook "04" contiene la definición del modelo de ML usado, así como los distintos experimentos para definir las configuraciones más adecuadas del modelo final.
